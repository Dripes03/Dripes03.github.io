Project Overview

This was my first large-scale project at TGA, where I served as a Technical Artist. Spite: Blood and Gold was a third-person action game using Diablo III as a reference.

Production of the game spanned over 14 weeks(20h/week).

My Contributions

My contributions to the project included developing visual effects, shaders and tools for the development pipeline.

Diablo Camera Tool

A blender tool writen in Python for graphical artists to import the exact camera angle from Diablo III. This was used to create assets in the correct metrics and allow the developer to get a rough preview of how the assets would look in the game without having to import them into the engine.

Blender tool demonstration

LUT Colour Grading

I developed and implemented LUT (Look-Up Table) colour grading solutions to ensure consistent and visually appealing colour schemes across different lighting conditions and environments in the game.

This project taught me the experiance of collaborating with a large team of multiple diciplines. I also learned the importance of clear communication and documentation in a fast-paced development environment.
